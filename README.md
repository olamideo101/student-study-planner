# Student Assignment & Study Planner

This repository contains my software development project for a Student Assignment & Study Planner.

The application will allow college students to manage:
- Courses
- Assignments
- Due dates
- Priorities
- Completed assignments

## Technologies

- Python
- Flask
- HTML
- CSS
- SQLite

The application will include a graphical user interface and a database connection.
